# Сквозная проверка правила

В окне редактирования секции кнопка **«Проверить маршрут правила»** принимает
домен и проверяет цепочку без изменения конфигурации и без перезапуска службы:

1. секция существует и включена;
2. сгенерированный конфиг sing-box доступен;
3. домен найден в прямом условии или локальном наборе правил;
4. первое совпавшее правило ведёт именно в выбранную секцию;
5. outbound секции существует;
6. DNS-ответ соответствует сгенерированному DNS-правилу, включая ожидаемый
   FakeIP;
7. Clash API получает ответ через outbound этой секции.

Если вышестоящая секция перехватила домен, результат показывает её outbound и
набор правил, на котором произошло первое совпадение. Отсутствующий или пустой
локальный набор считается ошибкой, а не молча пропускается.

Та же проверка доступна по SSH:

```sh
loghorizon check_rule_path Discord discord.com
```

Код возврата `0` означает, что вся цепочка прошла. Код `2` означает найденный
разрыв; подробности всегда печатаются как JSON.
