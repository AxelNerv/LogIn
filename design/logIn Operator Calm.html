Bootstrap DNS-серверы

Разрешают домены вышестоящего DNS и VPN-серверов. Тоже с резервом по порядку.

Перезапись TTL для DNS

Время кэширования DNS-записей в секундах.

Отключить QUIC

Может исправить маршрутизацию видео, но также способен сломать отдельные VPN-конфигурации.

Don't Touch My DHCP!

logIn не будет изменять вашу существующую конфигурацию DHCP.

При включённом Don't Touch My DHCP автоматическая настройка DNSMASQ пропускается. Для новой отдельной Wi-Fi-сети logIn отдельно покажет необходимые DHCP-изменения и не применит их без подтверждения.
Сейчас сохраняется только состояние прототипа.
